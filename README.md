# 🦖 Gamblesaur

Live moneyline & spread velocity tracker with real DraftKings odds.

## Features
- Real odds from DraftKings + FanDuel via The Odds API
- Live scores from ESPN (NBA, MLB, NFL, NHL, Soccer, Tennis)
- Moneyline & spread velocity tracking
- Adaptive tick speed (slow normally, fast in clutch time)
- Auto-generated daily picks ranked by edge
- Session performance tracker
